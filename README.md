# Orchestration Gateway

A Nextcloud app that provides an admin settings section to manage webhooks, enabling Nextcloud to trigger automations in external workflow orchestration services.

You can use this app to register, update and delete webhook listeners in the Nextcloud admin settings. Triggers can be set on Nextcloud events from Files, Forms, Tables, Calendar and many more. You can also configure event filters, user ID filters and choose which authorization tokens to include for every webhook. See the [webhook listeners documentation](https://docs.nextcloud.com/server/stable/admin_manual/webhook_listeners/index.html) for more information.

The app includes a specialized form to easily set up webhooks with Budibase.
